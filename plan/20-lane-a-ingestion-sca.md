# Anvil Implementation — Lane A: Ingestion And Deterministic Scanning

## Overview

Lane A is the zero-inference half of Anvil (spine S1): a tiered conditional-GET poller that fills a single
SQLite+FTS5 cache from licence-tiered advisory feeds, bootstrapped from bulk archives rather than git
history, plus two independent collectors — host package inventory and repo SCA — that feed a shared
deterministic version comparator. No model appears anywhere in this lane; the only "intelligence" is a
version-range comparator and a licence-tier gate. Trivy (Apache-2.0) is the deterministic scanning core per
spine S4/S12, vendor-pin-and-monitored with a CLI fallback because it exposes no stable library API. Every
step below is a worker packet in the `00-ROUTING.md` format, ordered so that config and cache schema land
first, the two collectors and the poller/bootstrap pair run in parallel once the schema exists, and the
comparator + record emission close the lane out under a cross-family critic gate.

## Dependency Summary

**External, not owned by Lane A:**
- The canonical SARIF-shaped record schema and the **one fingerprint algorithm** (spine S6) are owned by
  the record-schema lane. Lane A's emission step (A.19) populates Lane-A-owned fields
  (`remediable_by_agent`, `as_of`, `staleness_seconds`, `parse_degraded`, `anvil/trust`, `license_spdx`,
  `license_manual_note`) into that schema — it must not invent a competing fingerprint or record format.
- A GitHub PAT (or App installation token) with public-repo read scope, provisioned by the orchestrator/ops,
  not generated by any Lane A step. Without it, conditional GETs fall onto the 60/hour unauthenticated
  budget (research/06 §"Rate-limit exemption is narrower than commonly cited").
- Go module baseline: `modernc.org/sqlite` (pure-Go, FTS5-capable, no cgo — spine S12) must already be a
  project dependency before A.2 runs.
- systemd (or an equivalent cgroup controller) for the resource-confinement units referenced in A.9/A.10
  (research/12 §6, Table B).

**Internal to Lane A (this file's own step graph):** feeds.yaml config (A.1) gates the cache schema (A.2),
which gates sanitisation (A.3) and licence-tier layout (A.4) in parallel, which gate the poller, bootstrap
importer, host collector, repo collector, and DB accelerator (A.7–A.11) in parallel, which gate delta
ingestion (A.14), which gates self-heal and drift/tombstone handling (A.15/A.16) in parallel, which gate the
comparator (A.17), which gates record emission (A.19) and its critic (A.20), which gate the final
conformance harness (A.21).

**File layout convention used by every packet below** (Go, no cgo, `modernc.org/sqlite`):

## Cache Schema

```sql
-- Per-feed polling state. Cadence itself lives in feeds.yaml (A.1), never here or in code.
CREATE TABLE feed_state (
  feed_id              TEXT PRIMARY KEY,
  etag                 TEXT,
  last_modified        TEXT,
  watermark            TEXT,                 -- feed-specific cursor: lastModStartDate, delta filename, git ref
  last_ok_at           TEXT,                  -- ISO8601
  consecutive_failures INTEGER NOT NULL DEFAULT 0,
  license_tier         INTEGER NOT NULL CHECK (license_tier IN (0,1,2,3))
);

-- One row per (source, source_id). NEVER key on CVE ID alone (research/06 Risk #2: a cvelistV5 outage
-- must be able to swap to EUVD/OSV/GHSA without touching detector code).
CREATE TABLE advisory (
  source               TEXT NOT NULL,        -- 'cvelistv5' | 'ghsa' | 'osv' | 'redhat-csaf' | 'ubuntu' | 'alpine' | ...
  source_id            TEXT NOT NULL,        -- native ID within that source
  cve_id                TEXT,                 -- nullable alias, never the primary key
  published              TEXT,
  modified                TEXT,
  state                    TEXT NOT NULL DEFAULT 'published',  -- 'published' | 'withdrawn' | 'rejected'
  tombstoned_at             TEXT,
  severity                   TEXT,
  cvss_vector                 TEXT,
  cvss_score                   REAL,
  epss_score                     REAL,
  epss_as_of                       TEXT,
  kev                                INTEGER NOT NULL DEFAULT 0,
  license_spdx                        TEXT,   -- SPDX id where a LICENSE file body states one
  license_manual_note                  TEXT,  -- quoted operative sentence when SPDX is null/NOASSERTION/wrong (spine S8)
  license_tier                          INTEGER NOT NULL CHECK (license_tier IN (0,1,2,3)),
  anvil_trust                            TEXT NOT NULL DEFAULT 'untrusted',  -- spine S6: untrusted|anvil_generated|verified
  as_of                                    TEXT NOT NULL,
  staleness_seconds                         INTEGER NOT NULL DEFAULT 0,
  parse_degraded                             INTEGER NOT NULL DEFAULT 0,
  data_version                                TEXT,  -- e.g. CVE record dataVersion 5.0/5.1/5.2
  raw_json                                     BLOB NOT NULL,
  PRIMARY KEY (source, source_id)
);
CREATE INDEX idx_advisory_cve_id ON advisory(cve_id);

CREATE TABLE cve_alias (
  cve_id    TEXT NOT NULL,
  source    TEXT NOT NULL,
  source_id TEXT NOT NULL,
  PRIMARY KEY (cve_id, source, source_id),
  FOREIGN KEY (source, source_id) REFERENCES advisory(source, source_id)
);

CREATE TABLE affected (
  id              INTEGER PRIMARY KEY,
  source          TEXT NOT NULL,
  source_id       TEXT NOT NULL,
  ecosystem       TEXT NOT NULL,   -- 'deb' | 'rpm' | 'apk' | 'npm' | 'pypi' | 'go' | ...
  package         TEXT NOT NULL,
  purl            TEXT,            -- pkg:deb/debian/openssl@... (ECMA-427 / purl-spec, MIT)
  introduced      TEXT,
  fixed           TEXT,
  distro_backport INTEGER NOT NULL DEFAULT 0,  -- true when the range came from a vendor/distro advisory,
                                                -- not upstream — this is what defeats the CVE-2023-32681 /
                                                -- RHSA-2023:4520 backport false-positive class (research/12 §3)
  FOREIGN KEY (source, source_id) REFERENCES advisory(source, source_id)
);
CREATE INDEX idx_affected_pkg ON affected(ecosystem, package);

-- External-content FTS5: indexes advisory text without duplicating raw_json, and supports incremental
-- INSERT/DELETE — no full reindex per sync (research/06 Recommendation §5).
CREATE VIRTUAL TABLE advisory_fts USING fts5(
  description, references_text,
  content='',
  tokenize='porter unicode61'
);
-- Upsert contract: writers issue row-scoped INSERT OR REPLACE for exactly the (source, source_id) rows
-- touched by the current sync batch; no code path may DROP or rebuild this table.

-- Backs the segregated on-disk mirror layout, not just a DB row.
CREATE TABLE license_dir_manifest (
  directory    TEXT PRIMARY KEY,   -- e.g. 'mirror/tier2/ubuntu'
  tier         INTEGER NOT NULL,
  license_file TEXT NOT NULL,      -- path to the LICENSE file physically checked into that directory
  spdx_id      TEXT
);

-- Lane A's own output: host + repo findings, pre-canonical-record-schema.
CREATE TABLE finding (
  id                   TEXT PRIMARY KEY,     -- Lane A local id; canonical fingerprint owned by the record-schema lane
  collector            TEXT NOT NULL,        -- 'host' | 'repo-sca'
  source                TEXT NOT NULL,
  source_id              TEXT NOT NULL,
  package                  TEXT NOT NULL,
  installed_version          TEXT NOT NULL,
  ecosystem                    TEXT NOT NULL,
  remediable_by_agent            INTEGER NOT NULL,  -- spine S6: always 0 for collector='host'
  as_of                             TEXT NOT NULL,
  staleness_seconds                   INTEGER NOT NULL DEFAULT 0,
  anvil_trust                           TEXT NOT NULL DEFAULT 'anvil_generated',
  detected_at                             TEXT NOT NULL,
  FOREIGN KEY (source, source_id) REFERENCES advisory(source, source_id)
);
```

## Exit Criteria

All objectively checkable, exercised by A.21's conformance harness unless noted:

1. **No hard-coded feed cadence or URL.** `grep`-style scan of the compiled `internal/ingest/...` tree finds
   zero feed hostnames or interval literals outside `feeds.yaml`/`feeds.example.yaml`.
2. **Cache schema is idempotent and FTS5-backed.** Migrations apply cleanly to an empty file and to a file
   already at the latest version; `PRAGMA compile_options` / a runtime probe confirms FTS5 is active.
3. **304 costs zero rows written.** A poller test against an httptest 304 fixture leaves `advisory`/
   `affected`/`advisory_fts` byte-identical and updates only `feed_state.last_ok_at`.
4. **No unauthenticated request against a GitHub-hosted feed.** Every outbound request in poller tests
   carries an `Authorization` header when the target host is `github.com`/`api.github.com`/
   `raw.githubusercontent.com`.
5. **No cross-host redirect followed.** A poller test that returns a redirect to a different host than the
   configured feed URL asserts the client aborts rather than following it.
6. **Bootstrap never clones cvelistV5's full git history.** Static check / code-review confirms
   `internal/ingest/bootstrap/bootstrap.go` contains no `git clone` invocation for the `cvelistv5` feed ID.
7. **GHSA bootstrap uses blobless clone, not a bulk zip.** `internal/ingest/bootstrap/ghsa_clone.go` exists
   and is the sole bootstrap path for the `ghsa` feed ID.
8. **Delta ingestion performs row-scoped upserts only.** A 200-row synthetic delta batch produces exactly
   200 `INSERT OR REPLACE` operations and zero `DROP`/`CREATE VIRTUAL TABLE` statements, observed via SQL
   trace in the A.14 test.
9. **Tier 2 content never lands under `mirror/tier0/` or `mirror/tier1/`.** `Gate()` (A.4) rejects any
   attempt to do so; `mirror/tier2/{ubuntu,alpine,osv}/LICENSE` exist and are non-empty.
10. **CISA KEV is correctly admitted despite `NOASSERTION` at the API layer.** A.4/A.6's test explicitly
    exercises this case using `license_manual_note`.
11. **Every advisory row carries `license_spdx` or a non-empty `license_manual_note`.** No row has both
    null.
12. **Every scraped string passes through `Sanitize()` before reaching the cache.** A.5's critic review
    confirms zero bypassing write paths; the fixture corpus of zero-width/bidi/HTML-comment injection
    strings is fully neutralised.
13. **Host collector never invokes a mutating package-manager verb.** A.9/A.12's allowlist test finds zero
    such call sites; the collector completes successfully under a non-root UID against a fixture.
14. **Host collector is not a resident daemon.** It runs to completion and exits; no watchdog/loop code
    exists in `internal/collector/host/`.
15. **Repo SCA collector degrades to a documented CLI path** — no direct dependency on Trivy `pkg/`
    internals without a CLI fallback annotated in code.
16. **Trivy-DB/Grype-DB accelerator content is never redistributed.** A.11/A.13's test confirms no write
    path resolves under `mirror/tier{0,1,2}/`, and the pulled artifact is tagged `consume_only` in its
    manifest.
17. **Grype accelerator refuses schema v5.** A synthetic v5 response is rejected by the version gate.
18. **Comparator is deterministic.** Three repeated runs on the same fixed input produce byte-identical
    `MatchResult` output.
19. **Vendor-advisory-first precedence defeats the documented backport false positive.** The
    CVE-2023-32681/RHSA-2023:4520-shaped regression fixture produces no finding.
20. **Every match run reports coverage, never silent "clean."** `CoverageReport` is populated on every
    call, including the zero-findings case.
21. **`remediable_by_agent` is `false` for 100% of host-collector-sourced records**, with no code path,
    flag, or config key capable of overriding it (A.19/A.20).
22. **Withdrawn/REJECTED advisories are tombstoned, never deleted**, and dependent findings become
    invalidated rather than silently vanishing (A.16).
23. **Unknown CVE `dataVersion` values are persisted with `parse_degraded=1`, never dropped** (A.16).
24. **Weekly self-heal restores records the delta pipeline silently dropped**, verified against the
    synthetic missing-records fixture (A.15).
25. **A.21's harness passes end-to-end** on the fixed synthetic corpus with `go test` green in CI, and the
    two-consecutive-run diff attached as evidence shows zero unexplained deltas.

## Open Questions

1. **"Greenbone VT content" cannot be sourced.** The task brief names it as a Tier-2 example alongside
   Ubuntu/Alpine/OSV, but a full-repository search of `research/` found zero mentions of "Greenbone" in
   any file, including `research/01` and `research/06`. It is omitted from the Feed Table and Cache Schema
   pending a dedicated research pass; do not implement ingestion for it until sourced.
2. **`modernc.org/sqlite`'s own licence was not independently verified in this research pass.** Spine S12
   establishes it as the correct dependency technically (pure Go, FTS5-capable, no cgo) but neither
   research/06 nor research/01 states its SPDX licence. Read the LICENSE file body before A.2 ships, per
   spine S8's own compliance mechanic.
3. **cvelistV5 hourly-delta cumulative-vs-incremental semantics are inferred, not proven** (research/06
   Gaps: "I did not download two consecutive hourly zips and diff their file lists"). A.14 is written
   defensively (upsert-based, dedupes regardless), so this does not block implementation, but the exact
   cadence-vs-cost tradeoff in the Feed Table should be re-measured once real traffic exists.
4. **OSV `all.zip` and per-ecosystem sizes were not measured** in research/06 beyond the one aggregate
   figure (1.32 GiB, research/01 S8). A.8's bootstrap importer should be tested against real per-ecosystem
   downloads before the "pull only ecosystems the target repo uses" optimisation is trusted at scale.
5. **Ubuntu's own security pages state no licence for OVAL data at all** (research/01 S29) — the
   CC-BY-SA-4.0 tier assignment rests on OSV's characterisation (research/01 S7), not a Canonical
   statement. If Anvil ever ingests Ubuntu directly (not via OSV's export), re-verify against a Canonical
   legal page before trusting the Tier-2 assignment.
6. **Trivy's own DB distribution cadence (6h → 24h after the GHCR incident) is documented only in a
   maintainer discussion thread, not versioned docs** (research/06 S23). A.11's accelerator should treat
   Trivy's advertised refresh interval as unverified and poll conservatively.
7. **The hardening/compliance axis (OpenSCAP + ComplianceAsCode/SSG, CIS-exclusion enforcement) researched
   in research/12 §5 is out of this task's explicit MUST-COVER scope** and is not stepped here. It is a
   natural follow-on to Lane A (same host-collector infrastructure) but should be scoped as its own plan
   section by the orchestrator rather than folded in silently.
8. **Whether native Trivy library linking (vs. CLI-only) is ever revisited** depends on spine S12's own
   open item: "if the encoder HTTP round-trip dominates latency... Python becomes the stronger pick." That
   finding is about the ONNX encoder, not Trivy, but the same vendor-pin-and-monitor caution applies — A.10
   should be revisited if Trivy ever ships a documented `pkg/` stability contract.
